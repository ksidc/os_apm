# 고객 인프라 관리 효율화를 위한 GLPI 파일럿 테스트 제안

---

## 1. 개요

GLPI(Gestionnaire Libre de Parc Informatique)는 IT 자산 및 서비스 관리를 위한 오픈소스 기반 통합 솔루션입니다.  
본 문서는 인프라 운영 현황의 비효율 개선을 위해 GLPI 파일럿 테스트를 제안합니다.

---

## 2. GLPI 소개

### 2.1 주요 기능

- **IT 자산 관리**: 서버, 네트워크 장비, 라이선스 추적
- **헬프데스크 / 티켓 시스템**: 장애 및 변경 요청 관리
- **랙 / 데이터센터 관리**: U 단위 시각화, 전원, 포트 상태
- **변경 이력 추적**: 감사 이력 자동 기록
- **API 제공**: ERP 등 외부 시스템 연동 가능

### 2.2 특징

- 오픈소스(GPL)
- 웹 기반, VPN 환경에서 사용 가능
- 플러그인 확장 구조
- 한국어 지원

---

## 3. 파일럿 테스트 목적

### ▶ 현황 문제점

- 랙 공간, 장비 상태, 변경 이력 등이 **수작업**으로 관리
- 정보 불일치 및 반복 조회 발생

### ▶ 개선 목표

- 업무 효율 개선
- 장비 이력 신뢰성 확보
- 데이터 중앙화 및 실시간 접근

---

## 4. 주요 문제 및 GLPI 개선 방안

| 문제 영역 | 현재 문제 | GLPI 개선 방안 |
|-----------|-----------|----------------|
| 랙 공간 관리 | 수기 기록, 반복 질문 | 시각화된 랙 뷰, 실시간 상태 확인 |
| 장비 이력 추적 | 담당자에 의존 | 티켓 기반 자동 이력화 |
| 상면 구성 | 수작업 도면 작성 | 자동화된 상면 등록 및 변경 관리 |
| 정보 공유 | 정보 소유자 불분명 | 중앙 DB + 권한 기반 접근 제어 |
| ERP 연동 | 구축/확장 한계 | 필요한 데이터만 API 연동 |

---

## 5. 추진 일정 및 단계

### **1단계: 환경 구축 (1~4주차)**

- GLPI 설치 및 기본 플러그인 설정
- 주요 고객사 2~3곳 데이터 등록
- 랙 구성도 및 자산 입력

### **2단계: 파일럿 테스트 (5~8주차)**

- 실제 업무와 병행 적용
- 티켓 발행 → 처리 → 이력 검증
- 각 부서 피드백 수렴

### **3단계: 단계적 확대 (~3개월)**

- 주요 고객사부터 적용
- 사용자 교육 및 매뉴얼 제공

### **4단계: 안정화 및 최적화 (~6개월)**

- ERP 연동, ISMS 대응
- 알람, 리포트, 백업 기능 적용
